# Employee Expense Process Improvement

## Project Overview

In this project, I looked at an employee expense process where an online system was already being used, but employees were still experiencing delays with approvals and reimbursements.

I looked at the current process, identified some of the main problems and suggested changes that could make the process quicker and clearer without removing the required approval checks.

## What I Looked At

- The current expense claim process
- Problems with manager approvals and finance processing
- Employee visibility of claim progress
- Where automation could help improve the process
- Business requirements for the improved process
- Stakeholders affected by the changes
- How the changes could be introduced and supported

## Proposed Improvements

I proposed:

- Automatic checks for required information
- Notifications for new claims
- Reminders for outstanding approvals
- Better claim status tracking
- Clearer visibility of approved claims for Finance
- Automatic payment updates for employees

## Recommendation

Rather than replacing the existing system, I recommended improving the current process and using automation to reduce delays and make the process easier to manage.
